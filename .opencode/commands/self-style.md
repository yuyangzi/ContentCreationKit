# 指令

这个文件是累积型风格档案，不是一次性的 diff 分析脚本。

## 用法

- **有新样本**：给一份「仓库稿 → 我改过的发布稿」，对比后把新规律并入规则表，同时在「案例库」追加一行，并销掉被证实的待验证项。
- **没有新样本**：只输出当前档案，不编造规则。
- **写稿阶段**（`/create-draft`、`/to-article`）：`强` 规律当硬约束，`弱` 规律当倾向。

## 什么算规律

一条差异能反过来指导下一篇，才算规律。某节被删了不算，除非能说出删它的条件。一次性的内容取舍记进案例库，不进规则表。

`强` = 两篇以上一致出现；`弱` = 单篇观察，待验证。

# 规则表

## A. 标题

### A1 冒号前的比喻，正文没兑现就删　`弱`

| | |
|---|---|
| 改前 | 判断也是接口：快决策模型接入 agent 的工程模式 |
| 改后 | 决策模型接入 Agent 的工程模式 |

正文只有结尾一句提到"接口"，"判断=接口"这个隐喻没有展开。冒号结构本身没被禁用（`Agent生产化鸿沟：复合误差的数学解剖` 就保留了），被删的是没落地的比喻。

**操作**：标题出现「X 也是 Y」「A 是 B 的 C」句式时，回正文找对应段落；找不到就砍前半，用后半当标题。

### A2 标题里的技术名用官方写法，正文保持口语　`弱`

`agent` → `Agent`，只改标题。正文五处仍是小写 `agent`。

标题是门面，按厂商写法；正文按自己的说话习惯。不必为统一而全文替换。

### A3 去掉自造的限定前缀　`弱`

`快决策模型` → `决策模型`。前缀"快"只在和"慢模型"成对时才有意义，单独出现是读者的负担。

## B. 术语

### B1 对比关系用读者已有的类别，不发明相对标签　`弱`

| | |
|---|---|
| 改前 | 快模型 / 慢模型 |
| 改后 | 决策模型 / 大模型 |

三处替换：正文段落、代码注释、落地清单。"快/慢"要求读者先接受一套自造坐标；"决策模型/大模型"直接用业内现成的两个类别。

**操作**：出现「X 模型 / Y 模型」这类相对命名时，先问读者有没有这个坐标。没有就换成已知类别。

### B2 术语替换要全局扫一遍　`弱`

这篇留下了残留：`快慢分工里它承担判断，不承担规划` 还挂着旧说法，其余全部换完。

替换是逐处手改，不是搜索替换。定稿前做一次全文术语扫描。

## C. 裁剪

### C1 修稿是纯减法，不做句内改写　`弱`

对比结果：新增句子 0 条。所有改动只有三种——删段落、换词、改标题。

**含义**：改稿动作是"找到旁支、整块拿掉"，不是"把每段改短"。写稿时行文可以放松，结构必须清楚哪块能整块摘掉。

### C2 能独立成节的旁支，最先被删　`弱`

删掉两个完整章节：

- `阈值是测出来的，不是拍出来的`——自洽性实验、选择性分类理论、回归集建法、旁路四格表
- `账要按调用次数算，不是按单价算`——成本算式、两张表、445 倍与 8–27 倍的口径辨析

共同点：抽出来能单独成文，删掉不影响主线闭环（Decode → 拆分 → fan-out → 闸门 → 缺陷 → 清单）。

**操作**：结构设计阶段就标记哪些节是"可以独立成文"的。它们是最可能被整节删的候选，论证不必写得太重。

### C3 可清单化的结论留下，需要论证的结论跟着章节走　`弱`

两节的命运不同：

- 阈值节的结论能压成清单条目，落地清单第 4、5 条（进回归集、先旁路再灰度）原样保留
- 成本节的结论压不进条目（"账按次数算"需要算式撑着），整块消失，全文再没出现过

**操作**：想让一个判断活下来，把它写成可以脱离论证独立成立的短句，放进清单。

### C4 数据型表格删，定义型表格留　`弱`

| 表格 | 去留 |
|---|---|
| 三种原语定义 | 留 |
| 失败模式与工程处理 | 留 |
| 模型 vs 人工 四格对照 | 删 |
| 调用量成本对照 | 删 |

留下的两张承载"定义"和"清单"，删掉的两张承载"算账"和"推演"。数据型表格占版面大，结论可以一句话说完。

### C5 信源自谦段压成括号，不单独成段　`弱`

删掉的一整段：

> 需要说明的是，Jev 的架构、权重和训练方法都没有公开。上面这套 Prefill/Decode 的切分，是官方口径加上外部复现者的推断……

这类段落的作用是标注不确定性，但单独成段会打断节奏，也削弱了刚立起来的解释。作者的处理是整段删除，严谨性交给参考来源。

**建议的折中**：不要单独成段，压成一句括号附在论断后面，或放进文末注。删掉不写等于放弃了，写成一整段又太贵。

## D. 句子

### D1 删语气副词　`弱`

`回退链还要配预算` → `回退链要配预算`。一个"还"字，去掉后句子更硬。

同类：`需要说明的是`、`值得一提的是`、`事实上`。

### D2 代词换实体　`弱`

`它不擅长的活，文档自己列了清单` → `决策模型不擅长的场景`

标题层级不要出现"它"，读者翻到这一节时已经离开上一段的语境。

### D3 口语名词换书面名词　`弱`

`不擅长的活` → `不擅长的场景`。正文里"活"很自然，标题和清单里换成书面词。

### D4 删元叙述，保留引用事实　`弱`

删掉的是 `文档自己列了清单` 这个动作，保留的是 `TypeSafe 的已知缺陷页列了九个不应该使用的场景`。

区别在于：交代"谁说的、说了几条"是信息；交代"文档替我列好了清单"是作者在讲自己的取材过程。

## E. 不动的部分

这三类内容在删掉约三分之一篇幅后原样保留，说明它们是硬骨架：

1. **代码块**——两个全部保留，包括注释。示例代码是这篇文章不可压缩的部分。
2. **带具体数字的第三方评测**——108 条声明、ECE 0.066/0.061/0.067、Brier 0.033 降到 0.026。数字越具体越舍不得删。
3. **反直觉判断连同它的论文引用**——"更准和更校准不是同一个方向"保住了 Ferrer & Ramos 那条引用。引用是否保留，看它是否在支撑一个反直觉结论，不看它是否新鲜。

# 与 StyleRule 的关系

| StyleRule | 本次差异的对应 |
|---|---|
| §1 作者隐身 | D4 直接命中：删"文档自己列了清单" |
| §2 弱化绝对 | 有张力，见下 |
| §3 论据收敛 | C1–C4 是这条在章节层的放大：论据够了就收，收到能整节删 |
| §4 叙事纯净 | C2 的旁支判定与"段间不岔路"同源 |
| §5 列表化 | C3 的载体：被删章节的结论靠清单活下来 |
| §6 破折号约束 | 本次未涉及 |

**张力点**：§2 要求弱化绝对，本次却删掉了信源自谦段。两者不冲突，是分层——

- 判断句（"XX 不会发生"）→ 加限定
- 信源可靠性（"这个架构是推断的"）→ 压成括号，不单独成段，也不假装确定

# 写稿自查

按顺序过一遍，能省掉大部分发布前的修改：

1. 标题有没有正文没兑现的比喻？
2. 有没有自造的相对标签（快/慢、轻/重、新/旧）可以换成现成类别？
3. 哪几节可以独立成文？标记出来，论证写轻一点。
4. 每个被删风险高的章节，结论能不能压成一句进清单？
5. 表格是定义型还是算账型？算账型的直接改写成一句话。
6. 有没有"需要说明的是""值得一提的是"开头的自谦段？压成括号或文末注。
7. 标题和清单里还有没有"它""这个""该"这类要靠上下文才能读懂的指代？
