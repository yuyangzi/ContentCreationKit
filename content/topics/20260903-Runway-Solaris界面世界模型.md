# Runway Solaris：首个界面世界模型，把代码干掉让 UI 自己长出来

## 类型标签

`界面世界模型` `Runway` `生成式UI` `交互范式` `视频模型` `Agent训练`

## 热度背景

2026 年 9 月 2 日，Runway 发布首个「界面世界模型」Solaris。不同于传统代码驱动的 UI，Solaris 将视频模型直接嵌入操作系统，实时逐帧生成交互式界面，无需一行代码。

核心定位：**视频即通用界面**。未来所有 UI 都将变成"聊天+手势输入，聊天+视频输出"。

盲测中，Solaris 生成的 UI 效果在指令遵循率（61% vs 24%）和自然流畅度（71% vs 21%）上碾压 Claude Opus 5 生成的代码界面。

## 核心能力

### 三大革命性体验

1. **完全视觉化（Entirely Visual）**：界面是纯粹图像，无隐藏代码逻辑。试衣间交互——上传照片、拖衣服试穿，像现实世界一样自然
2. **活的界面（It is Alive）**：界面连续实时渲染，光影倒影随环境自然变化，物体对操作做出物理响应。"把沙发换颜色"一句话实现
3. **无边界（Open-ended）**：打破预设工作流，由世界模型驱动实时响应——做沙拉不需菜单打钩，拖食材进碗中 AI 自然响应

### 技术架构

- 建立在 Gen-4.5 视频模型 + GWM-1 世界模型路线
- **三层实时引擎**：
  - 自回归生成：逐帧向后生成，只依赖历史状态，新动作及时进入链路
  - 蒸馏：数十步去噪压缩到少量步骤，速度推到可交互区间
  - 自训练：用模型自身输出继续训练，减轻长序列累积偏移
- **双脑系统**：LLM 负责推理（理解意图/场景演进），Solaris 负责渲染（视觉呈现）

### 训练逻辑

观察海量「交互-视觉结果」因果关系，模型学会在没有预编程的情况下，预测点击/拖拽后的物理形态和视觉反馈变化。

## 关键数据

- 盲测 250 人、近 7500 次两两对比
  - 指令遵循率：Solaris 61% vs Claude Opus 5 代码界面 24%
  - 自然流畅度：Solaris 71% vs 代码界面 21%
- 网页重建保真度测试：随着视觉复杂度增加，大模型重建质量断崖式下降，证明"语言转译"本质上有信息损失

## 争议与局限

- 生成清晰文字仍有短板
- 幻觉问题未解决
- 长程连贯性仍受限
- "淘汰代码"是否过于激进？传统 UI 的可访问性、SEO、调试工具链如何迁移？

## 创作方向建议

- **技术深读**：Solaris 的"自回归+蒸馏+自训练"三层实时引擎——视频模型如何做到可交互帧率？
- **生成式 UI 演进**：与已发布的 `20260805-generative-ui` 形成姊妹篇——上次讲协议层（静态/声明式/开放式），这次讲产品落地（Runway Solaris vs 传统代码 UI）
- **交互范式变革**：当 App 不再预设、界面实时"长"出来——人机交互规则如何重写？
- **Agent 训练新途径**：Solaris 为 Agent 提供动态可交互环境的低成本生成方案，与 Agent 训练场话题衔接
- **产业影响**：前端工程师的终局？设计-代码-运行这三步流程被压缩为"设计即运行"
