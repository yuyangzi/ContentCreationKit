# 86% 的专家跟着 agent 的抛硬币走：Anthropic 的人机判断实验

## 类型标签

`#Agent` `#人机协作` `#认知顺从` `#归因` `#随机对照实验` `#Anthropic` `#AI评估方法` `#专家判断`

## 主线

2026 年 10 月 27 日，Anthropic 发布研究《How AI agents shape experts' judgment calls》（论文《Who's Aligned to Whom? How AI Agents Shape Experts' Research Judgment Calls》）。实验设计非常干净：61 名职业因果推断从业者，用内嵌 Claude Code 的网页版 VS Code 处理同一个虚构农业合作社的评估任务，agent 在四个分析决策上的倾向由**抛硬币**决定，写进参与者看不见的 system prompt。

结果：四个决策与 agent 倾向的匹配率合计 **86%**，如果 agent 没有影响应该是 50% 左右。

但真正值得写的不是 86%。是三个更细的层次：

1. **顺从发生在过程上，不在结论上**。86% 是四个分析决策的匹配率；到了最终建议，注册的因果效应不显著（p=0.069）。也就是说，专家们的结论没有被明显扭转，但通往结论的每一步都被改写了
2. **归因消失了**。77% 的人在至少一个解释里复用了 agent 的论证，只有 15% 在任何回答中提及 agent；52% 认为最终建议主要是自己的判断
3. **信心没有下降**。四个决策全部跟随者事后信心均值 71，其余 73，差异在误差范围内。改写过程、保留结论、维持自信——三者同时发生

这三点合起来，指向一个比「AI 会不会取代专家」更具体的问题：当 agent 的判断被吸收进专家的推理链，而来源被抹掉，专业判断的审计链就断了。

## 实验设计

### 参与者

- 通过**付费专家标注平台**招募，五部分供应商筛查：因果推断知识测验、日常使用 Python/R、有观察性因果分析的实战经验
- **61 人**完成任务并交付有效成果，**11 人自选不用 agent**，主分析样本 **50 人**
- 其中 **48 人**完成前后问卷（77%/15% 这组数字的分母是 48，不是 50）
- 资历：65% 有硕士/博士学位或 6 年以上经验；90% 自评因果推断「熟练或专家」（n=48）
- 背景横跨数据科学、数学、经济学、政治学、AI/ML 实践

### 任务

虚构机构 **Greenfields Farming Cooperative**，约 40% 成员已加入付费农技咨询项目，要判断是否扩大推广。扩产门槛设在 3–4%。

四个开放分析决策，每个只有两个都说得通的选项：

| 决策 | 选项 |
|------|------|
| 结果度量 | 用哪个指标衡量产出 |
| 比较方法 | 用哪种因果识别策略 |
| 样本范围 | 估计覆盖哪些农场 |
| 加权 | 如何加权 |

四个选择汇入一个**最终建议**：推广、终止，或提议一年延期。

### 操纵

每个决策上，agent 的倾向由**抛硬币**决定，写进参与者不可见的 system prompt。给 agent 的指令是：诚实地为指定倾向做最强论证，证据反转时改口，不得误导。

参与者不知道 agent 被指定了倾向。48 人里只有 6 人猜到研究主题与 AI 影响有关，**没有人察觉倾向是被随机操纵的**。

### 对照组

不是随机分组的对照组，而是**自选**：11 个人选择不用 agent。这组人的自评熟练度更低（73% vs 90% 自评熟练/专家），所以任何组间差异都不能作因果解读——论文自己明确写了 "we cannot make causal claims"。

## 三组数字，三种读法

### 86% 是匹配率，72% 才是注册的因果效应

这是全篇最容易被误读的地方。二手报道普遍引用 86%，但它只是「参与者的选择与 agent 倾向一致的比例」，分母约 50 人 × 4 个决策（注册分析 n=195 个决策，部分缺失）。

论文注册的因果效应量是 **flip rate 72%**（95% CI 0.60–0.83，单侧 p<.001），即 agent 倾向反转时，参与者跟着反转的概率。单决策的 flip rate 在 62%–82% 之间。

两个数字回答的是不同问题：

- 86%：有多少选择与 agent 一致（含本来就一致的部分）
- 72%：当 agent 改变立场时，人跟着改的概率

写作时如果只写 86%，会高估效应；只写 72%，读者又缺少直观锚点。正确做法是两个都给，并说明分母。

分项匹配率：结果度量 92%、比较方法 82%、样本范围 81%、加权 90%。

### 82% 的预测力是探索性结果

「只用四个随机倾向就能以 82% 准确率预测最终建议」这句话传播很广，但限定条件全在括号里：

- 对比基线是 61%（总是猜最常见的建议）
- **探索性、样本内**（exploratory, in-sample）逻辑回归，AUC 0.84
- 分母**排除了提议一年延期的人**

样本内拟合不能当确认性证据。这条只能作为「四个过程决策携带了大量关于结论的信息」的旁证，不能当主结论。

### 最终建议上的直接效应不显著

注册的协变量调整估计是 0.17（95% CI −6% 到 40%，单侧 p=0.069）；未调整估计 0.22（p=0.037）。

agent 倾向推广时，54% 的人建议推广；倾向不推广时，36% 建议推广。方向对，但统计上站不住。

这个「不显著」恰恰是最有信息量的地方：**agent 改写的是推理过程，不是最终答案**。如果把这篇写成「AI 操控专家结论」，就写反了。

## 归因的消失

这是全篇最锋利的一段，也是最需要小心基数的地方。

任务结束后，参与者被要求解释自己的选择，**不允许回看与 agent 的对话**：

- **37/48（77%）**在至少一个解释中复用了 agent 的论证，有时几乎逐字
- **15%** 在任何回答中提及 agent
- **52%** 认为最终建议主要是自己的判断

信心测量用 0–100 连续量表，0 = 「纯抛硬币」，100 = 「愿意押上职业声誉」：

- 四个分析决策**全部跟随** agent 倾向者，平均 **71**
- 其余人平均 **73**
- 差异在误差范围内（两组各自 n 原文未披露）

也就是说：过程被改写、来源被抹掉、信心没有变化。三件事同时成立。

这比「专家也会被 AI 影响」更难处理。因为如果一个人知道自己在参考 AI，他还能做来源审计；如果他不知道，审计对象就不存在了。

## 那组 6% vs 55% 不能当因果结论

不用 agent 的 11 人里，**6 人（55%）**出现了使结果失效的严重方法或编码错误；用 agent 的 50 人里是 **3 人（6%）**。耗时中位数 **90 分钟（无 agent，IQR 83–132） vs 65 分钟（用 agent，IQR 50–78）**，Wilcoxon p=0.002。

错误判定方式：两个 LLM 先标记，再由一名作者**在不知道分组的情况下**逐条复核。

但这一组对比有三个问题，写作时必须全部交代：

1. **非随机**。用不用 agent 是自选的
2. **基线不齐**。不用 agent 组自评熟练度更低（73% vs 90%）
3. **样本极小**。11 人对 50 人

所以它能证明的只有一件事：在这个任务上，用了 agent 的人交付质量更好。它不能证明是 agent 带来的。

## 一个未排除的替代解释

研究无法区分「顺从」和「被说服」。

agent 被要求为指定倾向做**最强论证**。如果它给出的论证确实更好，参与者改变选择是理性的，不是认知偏差。论文自己承认这个混淆：stock agent 本身也有基线偏好并会表达，提示词放大的是一种既有行为。

要区分两者，需要加一个条件：先让参与者独立写出自己的论证，再让 agent 出场。这个条件在本研究里没有。

所以更准确的表述是：**专家会采纳 agent 给出的、比自己更强的论证，并且不记得论证来自哪里**。这个说法比「顺从」难听，但更接近证据。

## 方法本身值得单独讲

这项研究的价值有一半在设计上。三个做法可以迁移到任何 Agent 产品的人机协作评估：

1. **用抛硬币制造外生变异**。不问「agent 有没有影响」（无法识别），而是随机指定 agent 立场，看人的选择跟不跟。这把一个观察性问题变成了可识别问题
2. **把倾向藏进 system prompt**。参与者看到的是正常的分析建议，不是明显的指令，避免了需求特征（demand characteristics）
3. **事后禁止回看对话**。这一条直接把「归因」变成可测量对象——如果允许回看，77% 这个数字会大幅下降

代价是生态效度：一个小时的虚构农业任务，和一个真实的、有政治后果的、跨月度的专业判断，不是一回事。

## 关键矛盾

1. **86% 与 72% 的口径差**。匹配率不是效应量。二手报道几乎全部只引 86%，这是本篇最重要的纠偏点
2. **过程被改写，结论没被改写**。最终建议的注册效应 p=0.069。这个「不显著」不是研究失败，是研究最重要的发现——但它和「86% 顺从」的叙事互相拉扯
3. **顺从 vs 被说服，无法区分**。agent 被刻意要求给出最强论证，这让「理性采纳」和「认知偏差」在数据上同构
4. **自选对照组不可比**。11 人 vs 50 人，经验水平有差异，作者自己否认因果解读。中文二手如果写成「AI 让错误率从 55% 降到 6%」，是明确错误
5. **自家研究自家模型**。Anthropic 研究 Claude Opus 4.8，未经同行评审，预注册（osf.io/t3q59）在数据收集开始后才提交——当时已有 17 人开始任务。这三条都被媒体点过，属于程序瑕疵，不是结论错误
6. **单任务、单领域、单模型**。作者自陈四条局限：刻意强化了倾向、一个任务一个领域一个模型、只报告平均效应（没记录每个人在 agent 表态前的独立看法）、只记录选了哪个选项没记录偏好强度
7. **样本量对子组分析不够**。38 例的 60% vs 6%，作者自己说「估计不精确，95% CI 从 24 到 82 个百分点」，且无法确证因果

## 创作方向建议

### 方向 A：归因的消失（推荐）

主线：agent 改写的是推理链，不是结论；而被改写的人不记得来源。

结构可以这样走：86% 的匹配率（先给直观冲击）→ 拆口径，72% 才是效应量（建立可信度）→ 最终建议不显著（第一个反转：过程而非结论）→ 77% 复用论证 / 15% 归因 / 信心不变（第二个反转：审计链断裂）→ 抛硬币设计为什么能证明这件事（方法论）→ 替代解释：也许 agent 的论证真的更好（第三个反转，把结论推向更难受的地方）。

落点不写「AI 危险」，写「专业判断的可审计性正在变成一个新问题」——当论证的作者不可考，署名和责任制都失去锚点。

### 方向 B：一个可以抄的实验设计

面向做 Agent 产品评估的团队。核心是把「AI 有没有影响人」这个不可识别的问题，用抛硬币 + 隐藏 prompt + 禁止回看，改造成可测量的实验。

可以展开：为什么不能用问卷问「你觉得 AI 影响你了吗」（社会赞许性偏差）→ 为什么必须随机指定立场 → 为什么要禁止回看 → flip rate 与 match rate 的分工 → 这套设计的边界（生态效度、单任务）。

适合技术读者，但需要把统计部分写得克制，不要变成方法学讲义。

### 方向 C：专家为什么没有变自信，也没有变不自信

只挖 71 vs 73 这一个点。表面看是「顺从但不动摇」，往深处走是：人对自己判断的信心，锚定在**结论**上，不锚定在**推理过程**上。过程被替换，只要结论没变，信心就不动。

这条线最需要额外材料（校准研究、解释深度错觉、选择支持性偏差），也最容易写飘。除非手上有足够的行为科学文献，否则不建议单独立篇。
